# 🍔 HotPlate – Food Delivery Website

A full-stack Food Delivery Website developed during my internship at Tap Academy. The application provides an easy and efficient platform for customers to browse restaurants, order food online, and manage their orders, while administrators can manage restaurants, menus, customers, and orders through a dedicated dashboard.

## 🚀 Features

### Customer Module
- User Registration & Login
- Browse Restaurants
- View Food Menu
- Add Items to Cart

## 💻 Installation

1. Clone the repository

```
git clone https://github.com/yourusername/HotPlate-Food-Delivery-Website.git
```

2. Import as Maven Project.

3. Configure MySQL database.

4. Update database credentials.

5. Deploy on Apache Tomcat.

6. Run the application.
